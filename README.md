# MySQL Cyberpunk 2099 - Tron City 2099
Juego HTML5 Three.js - Moto Tron Lightcycle con estela letal

## Jugar
- **Principal (recomendado):** https://lemichiw-cyber.github.io/tron-city-2099/
- **Versión 80K:** https://lemichiw-cyber.github.io/tron-city-2099/80k.html

## Controles
- WASD / Joystick: Mover
- Mouse / Touch derecha: Apuntar
- Click / Espacio / FIRE: Disparar (1 SELECT, 2 WHERE, 3 DROP)
- Estela cian deja muro 6s que daña enemigos

## Características
- 25 edificios con colliders y ventanas procedurales
- 4 enemigos: NULL glitch, DRONE, SPIDER, DEADLOCK
- Ciudad neon 10 letreros + avenidas Tron
